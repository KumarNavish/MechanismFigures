## Mechanism

In a chiral magnet, a closed ring of twisted magnetisation can wrap one or more skyrmion strings. Each configuration has its own topological numbers.

## Where to look

1. Left column: the flat image of each state, as a microscope sees it in projection.
2. Middle columns: the same state as a 3D isosurface. The ring is the hopfion, and the tubes through it are skyrmion strings.
3. Right block: the bulk case. Follow one string up the box and find where a ring wraps it.

## Why it works

Each 3D state has its flat projection adjacent to it, thus the reader learns what the measurement looks like for each structure. All boxes share one camera and one colour code for the in-plane direction. A wire box gives each isosurface a frame.

## Take this

Pair each 3D structure with the flat image that an instrument records. Keep one camera and one bounding box for all states.

## Test your figure

Can the reader match each flat image to its 3D structure?

## Limit

The figure is a set of static states with no time. The rainbow hue code is hard for colour-blind readers. The 3D shapes come from simulation.
