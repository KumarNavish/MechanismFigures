# Repository map

For figure work, enter `skills/mechanism-figures/SKILL.md`. Do not load all cases.
For maintenance, run `python3 -m unittest discover -s tests -v` and `python3 tools/check_repo.py`.
Canonical reference metadata: `skills/mechanism-figures/assets/calibration.json`.
Canonical rubric: `skills/mechanism-figures/assets/rubric.json`.
Regenerate case pages/gallery with `python3 tools/build_gallery.py`; do not edit generated pages alone.
No model calls, credentials, paid services, telemetry, or global configuration changes belong in this repository.
The approved 20-reference/29-image canon is fixed in assets/approved-canon.json. Do not replace images with text-only entries, add self-generated calibration examples, or silently change the approved selection. Preserve all original attribution and source-specific rights; do not claim the repository MIT license covers third-party figures. Never substitute test success for scientific or aesthetic validation.
