# Choose the visual construction

First state one relationship supported by the project evidence. Identify the entities, units, update, fixed conditions, and the observation that could contradict the claim. [Scientific checks](fidelity.md).

| Relationship to expose | Construction | Current cases |
|---|---|---|
| Target outcome determines local controls | Target field or geometry, local program, implemented structure, observable consequence | `caustics`, `bioprint4d`, `mechanical` |
| A constraint persists through an evolving state | Aligned intermediate states with the fixed object visible throughout | `rfdiffusion`, `flow` |
| Algebra has a geometric or physical implementation | Indexed entities mapped onto actual edges, paths, or couplings | `alphafold`, `photonic-braids`, `graphcast` |
| Feedback changes a specific object | One object carried through observation, evaluation, and the return update | `dreamfusion`, `nerf` |
| One quantity hides direction | Joint state coordinates and a defined direction of change | `scvelo` |
| Local evidence produces global futures | An enlarged local transition rule linked to the population view | `cellrank` |
| A process propagates through a physical environment | Matched time-stamped scenes plus the local operation | `diffusive-machines`, `aardvark` |
| A contribution extends beyond the object silhouette | Spatially aligned layers and a matched edit/removal result | `genomnimatte` |
| Identity survives transformation | A localized probe transported between corresponding objects or spaces | `congealing`, `fip`, `torus` |
| Adjacency changes through depth or deformation | Linked boundary sections and an extracted local interface | `scutoids`, `kirigami` |

Choose two genuinely different candidate representations. Record each candidate's `construction`, `visible_gain`, `distortion_risk`, and `evidence_needed`. Rank scientific fidelity first, explanatory gain second, decoding effort third, and implementation cost fourth. A different palette is not a different representation.

Open two actual images through [the reference index](calibration-index.md). Read the complete figure for composition and its decisive panel for geometry and annotation. Record the image paths, hashes, visible observations, and project-specific mapping required by [style calibration](style-calibration.md).

Freeze a question and an intervention prediction before polishing. Draw the smallest complete mechanism and check whether the image supports the correct answer. Use the [construction guide](construct.md) for implementation and the [critique rubric](critique.md) before accepting the render.

An ordinary quantitative plot remains appropriate when it directly answers the question. Additional panels belong only when they establish the mechanism, define an ambiguous encoding, or state a necessary limitation. Missing evidence remains explicit rather than being filled with an attractive metaphor.
